# 手动验收清单（给主人，2026-11 · U7b 后最终形态）

> 设备与构建由主人手动验收；本文只列**按页面/操作**的勾选清单。
> 合并来源：真机 A–E 清单、`docs/theme-light-dark-checklist.md` §4、U7b 弹层手动检查点。
> 失败回报格式见文末。已知缺口列在 §7，**不要当缺陷报**。

## 0. 准备

- 安装当前 HEAD 的 debug APK（arm64/universal 均可）。
- 准备两个助手：一个普通；一个**曾经启用过「渐变背景」**（验证功能下线后不崩）。
- 准备浅色/深色两轮：设置 → 主题 → 主题模式（浅色 / 深色 / 跟随系统 + 系统切夜间）。

## 1. 主题（浅/深各过一遍）

- [ ] **T1 模式生效**：选浅色（系统仍深色）→ 整体变浅、状态栏/导航栏图标变深；选深色反之；杀进程重进仍保持。
- [ ] **T2 跟随系统**：系统切夜间，app 整体（含代码块/Mermaid）同步，不出现「页面深、代码浅」。
- [ ] **T3 三级层次**：浅色下卡片/分组/列表行能从页面底色分辨（不能一片白）；深色下不能比页面亮一大截。看设置首页、设置子页、日志页、统计页、工作区详情。
- [ ] **T4 正文层级**：onSurface > onSurfaceVariant > outlineVariant 三档可分；浅色下次要文字不糊成灰块。
- [ ] **T5 顶栏/弹层**：顶栏比页面高一档；弹层与底部弹窗（含 scrim）浅色下能与页面区分。
- [ ] **T6 选中态/强调**：chip、开关、按钮 primary/secondaryContainer 在深浅两套都读得出。
- [ ] **T7 AMOLED**：深色+AMOLED → 页面纯黑、卡片有暗→亮阶梯、顶栏不是黑页上的灰带；浅色开 AMOLED 不应变黑。
- [ ] **T8 代码/富文本**：代码块浅色 One Light、深色 One Dark；JSON 树、Diff 可读。
- [ ] **T9 系统栏**：状态栏/导航栏图标对比度随主题（浅深反色），下拉通知栏/手势条不错色。

## 2. 导航与返回

- [ ] **N1 60 条路由**：设置 → 各分组、抽屉 → 管理角色、探索市场、扩展管理/提示词/技能/工作区/日志/备份/WebView 等能正常进入，无空白页。
- [ ] **N2 入口 morph**：从卡片/行进入整页时有共享元素过渡（卡片→页面），返回时回落。
- [ ] **N3 深链**：其他应用分享文本到 KhatKit、翻译（PROCESS_TEXT）各一次；落点正常、可返回。
- [ ] **N4 返回单点**：页面逐层返回一层；根页返回退出应用；**不出现一次返回退两层**。

## 3. 弹层（MochiSheet / MochiDialog）

> **动画覆盖（重要）**：退场动画只在「宿主接 state、调用方持 state」的弹层上生效——直连
> `MochiSheet` 的 9 处页面、`PrimaryBottomSheet(state=…)` 的 17 个调用点、`EditStateSheetHost`。
> 其余走 `visible` 兼容层的 34 个调用点（其中 visible=true 恒定 16 处）多为条件组合，关闭即卸载，
> **即时消失属预期**，不算缺陷（逐条 file:line 见计划 §14.2.1）。

- [ ] **S1 sheet 起落（直连/state 页面）**：在状态直传的弹层上验证拉起/下滑关闭有动画与 backdrop、无「瞬间消失」。
- [ ] **S2 助手「新建助手」面板**：起落有收起动画；表单校验、保存行为不变。
- [ ] **S3 聊天输入栏「长按发送但未配 ASR」**：现在是 **dialog** —— 点「配置」跳设置、点外部关闭。
- [ ] **S4 思考强度**（聊天→模型菜单→思考强度）：**dialog** 内滑块吸附/选中等高正确，点外部关闭。
- [ ] **S5 多页 sheet**：带内部导航的弹层（如设置类多页面板）先退子页再关面板。
- [ ] **S6 冷门弹层行为不变**：导出选项（多复选）、备份 WebDAV/S3 表单、图片生成参数、日志长文本（两档可拖全屏）、MCP 配置/工具、提示词编辑、技能导入 URL、QQ 群列表、头像形状网格、权限策略、消息操作单、消息编辑文件列表、聊天附件面板、引导页内嵌面板、WebView 内弹层。
- [ ] **S7 Dialog 类**：短提示/单一动作使用 dialog（如思考强度、ASR 提示），点外部可关闭。
- [ ] **S8 返回手势**：弹层展开时返回先收弹层，再返回退页面（不双退）。
- [ ] **S9 visible 兼容层（预期即时消失）**：安全模式面板、权限说明、扫码结果、助手选择、图片生成参数、
  日志详情、MCP 配置/工具、引导页内嵌面板等——关闭时**允许瞬时消失**，只看内容/返回是否正常。

## 4. 组件与交互

- [ ] **C1 滑杆**：设置 → 界面 → 字体 → 聊天字体大小：拖动跟手、点击定位、两端夹取 50%/200%；TalkBack 是否能读出滑杆（已知可能无描述）。
- [ ] **C2 输入框**：设置 → 网络 → User-Agent 可输入；错误态（代理非法 URL）、密码显隐（服务商 API Key）、多行（系统提示/自定义 Body）各试一次。
- [ ] **C3 菜单（设置）**：设置页模型/语言下拉可弹出、选项点击回写并关闭。
- [ ] **C4 菜单（聊天）**：消息「更多」菜单可弹出、点击回写并关闭。
- [ ] **C5 触感**：拖动排序、长按、发送等触发触感（系统未关触感时）。
- [ ] **C6 按压反馈**：按钮/行按压有高光/缩放；连续快速点按不卡。
- [ ] **C7 涟漪裁剪**：点击涟漪在圆角内不发散成矩形。
- [ ] **C8 动效**：TabBar 切换有融球/滑动过渡；系统「减弱动效」开启时降级不崩。

- [ ] **P4** 探索市场 · **P5** 助手列表/助手详情/基础设定
- [ ] **P6** 扩展管理/提示词/技能 · **P7** 图片生成 · **P8** WebView · **P9** 工作区详情/终端/文件编辑
- [ ] **P10** 日志/请求详情 · **P11** 备份（本地/WebDAV/S3） · **P12** 引导页（Greeting，首次启动或清数据后）

## 6. 聊天与悬浮输入栏

- [ ] **H1 三态**：默认 / 键盘弹出 / 列表滚到底——输入栏不被遮挡、不跳动。
- [ ] **H2 长按发送**：配好 ASR 时长按发送可用；未配时弹 dialog（见 S3）。
- [ ] **H3 卡片弹层**：带 pager 的卡片左右翻页、内部导航、触底 load_more、边缘预测性返回。
- [ ] **H4 消息操作**：复制/引用/重新生成/编辑/删除/朗读菜单可弹出并生效。
- [ ] **H5 旧「渐变背景」助手**：聊天页正常显示、无崩溃；设置里无相关入口。

## 7. 已知缺口（验证时请忽略，不要报缺陷）

1. 抽屉背景**无模糊**（已退回 MD3 不透明层次色）。
2. 大屏：仅聊天页使用 `currentWindowDpSize`，平板/折叠未做 AdaptiveScaffold（建议 ≥840 侧栏双栏 / 600–840 导航轨 / <600 TabBar）。
3. MochiItem 缺口：长按/富行/组合语义仍用 `MochiMenuPopup`/`MochiMenuRow`（合计 8 处调用）。
4. 预设主题：入口已删、运行期不注入；旧数据保留不崩。
5. `RecordCardSheet` 无调用点（死代码候选），不影响 UI。
6. `visible` 兼容层弹层（34 个调用点，visible=true 恒定 16 处）**退场为即时消失**，不退场动画；
   护栏计数 51 与调用点清单见计划 §14.2.1。
