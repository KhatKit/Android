# 已落地 UI 改造的待验收项与观察记录

本页从已实现施工图迁出有效遗留，避免删除规划时丢失未验证事项。本次只维护文档，未执行真机测试；以下均为待复核记录，不能当作新近验证结果。

## 1. 七项 UI 修复的实机检查

旧施工图的七项均已落地；此前通过的是构建、单测、源码复算与评审，实际观感和交互仍待用户或后续测试人员检查。两种风格均需走查：

| 项目 | 操作与预期 |
|---|---|
| 聊天顶栏 | Miuix 展开/折叠标题点击均打开模型选择；长按有消息标题打开改名；空会话只提示；左右图标不被透明命中层遮挡；MD3 行为一致 |
| 抽屉间距 | 新建文件夹与顶栏有合适间距，滚动无重叠 |
| 输入光标 | Miuix 输入时光标可见，主题切换后仍可见 |
| 全屏编辑 | 上滑展开、松手提交/取消动画连续；系统返回先关闭编辑器 |
| 自动化提示 | 软件内与外部悬浮提示入退场不裁切，颜色、图标、时长符合预期 |
| 底部弹层 | Miuix 内容横向边距合理，输入和按钮不被压缩 |
| 关于页 | MD3 无动态流光背景，Miuix 保留自己的效果 |

重点边界：

- 顶栏图标槽宽在 `onSizeChanged` 前可能为 0，首帧自动化点击需防止透明命中区临时扩展。
- 大标题命中区及搜索输入仍有单侧 inset 口径，横屏旋转、侧边刘海/导航栏的实际边界待实机验证；折叠行已用逐侧并集。
- `defaultWindowInsetsPadding = false` 的横向口径曾记录不一致，当时全仓无调用者；若后续启用须重查。

## 2. 设置两风格对齐后的检查

已落地规则：条目并集补齐；模型副行取说明文案；提供商即改即存，名称离开编辑面时一次性 trim；通知取消不写设置、确认才写；主题/Web/提供商/模型提示词补齐 Miuix 变体。

待检查：两风格的外观三选、主题入口、字体与导入、轨迹审计、代理错误、设备信息、通知确认和四个变体页，操作目标及持久化结果一致。

以下为旧评审保留的观察项，本次未修复、未重新判定：

| 项目 | 原记录与后续动作 |
|---|---|
| 剪贴板弃用 | Web 页两风格均存在 `LocalClipboardManager` 弃用；历史“零 warning”说法不准确。可另行迁移 `LocalClipboard`/`ClipEntry` |
| 主题 helper 镜像 | Miuix 约 380 行、6 个私有 helper 与 MD3 同构；后续修改需双侧核对，适合单独抽共享逻辑 |
| 动态取色与主题操作 | Miuix 导入/新建恒可见，MD3 在关闭动态取色时可见；可能出现新建主题未立即生效，需统一可及条件或给解释 |
| 权限说明弹窗 | `PermissionRationaleDialog → Khromia AnimatedAlertDialog` 共用 MD3 观感；Miuix 分流仍是跨仓观察项 |
| 阿语回退 | `values-ar` 缺 `setting_package_page_device`、`setting_package_page_device_id`、`setting_package_page_loading`，回落英文 |
| 分组标题 | Miuix 主页 5 处分组未使用对应标题键；属呈现差异，需验证可读性 |
| 硬编码中文 | 探索市场、套餐激活等旧入口曾保留硬编码中文；翻译清理前先核对当前源码 |
